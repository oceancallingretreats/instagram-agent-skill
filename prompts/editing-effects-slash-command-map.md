# Ocean Calling — Slash command library (50 names)

**Platform accuracy:** The full downloadable ZIP includes 50 `.claude/commands/*.md` definitions for Claude Code. Installing those files enables project-level commands but actual image rendering depends on an available editor. Standard ChatGPT does not support user-installed native slash commands; a Custom GPT can interpret the strings as shorthand. The included local Python dispatcher accepts all names, renders seven basic image effects and returns an editing instruction for the remaining AI effects. It does not automatically integrate into Ocean Calling's video builder.

## Installation and examples

- Claude Code: copy the ZIP's `.claude/commands/` folder into a project, then enter `/outline` or another name in that project.
- ChatGPT: add this mapping and the custom-GPT instructions from the ZIP, then send `/outline` with your photo.
- Ocean Calling WSL: `python3 effects.py /outline image.jpg -o output.png`; requires Pillow. Video integration not yet installed.

The 50 phrases are newly authored as useful commands. The original tiny on-screen command labels could not be reliably transcribed from the screenshots.
